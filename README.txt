# Behind the Dark, There Is a Light — Website Starter

A responsive, static author/novel website for Esha Nadeem.

## Preview on your computer
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. The website works as a local preview without installing anything.

## Before publishing
- Your supplied hardcover mockup is included as `book-cover.png` and is shown in both the homepage hero and the order section. Keep this image in the same folder as `index.html`, `style.css`, and `script.js` when uploading.
- Replace the sample chapter titles and preview text with your real chapter titles and approved excerpts.
- Add your real book price, shipping information, and order contact.
- In `index.html`, find `YOUR-EMAIL@example.com` and replace it with your order email, or change the order button to your WhatsApp link.
- Add your Instagram profile link if you want it in the footer.
- Check all details before sharing publicly.

## Publish free using GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository, e.g. `behind-the-dark-light`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your website address will be shown in the Pages settings.

Google Sites is another no-code option, but it cannot directly host this custom HTML design as a complete website. For this particular template, GitHub Pages is the easiest free hosting route.

## Important
This starter does not process online payments or collect orders automatically. The order button is currently a placeholder email link. Add a real contact method for manual orders; a full checkout/store can be added later.
